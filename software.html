Open code behind FROST

The solvers, agents, and learning frameworks the team brings to FROST, and the FROST tooling that will ship with the first release. Data are released under CC-BY-4.0; code under OSI licenses.

AI agents

DMOpen source · Apache-2.0

DAFoam MCP server

He

A Model Context Protocol server that lets AI agents mesh, run, and optimize DAFoam cases. The planned FROST MCP server builds on it.

Repository
POpen source · MIT

PhysMiner

He, Gao

A multi-agent LLM framework for automated flow-component analysis: triple decomposition of the velocity-gradient tensor, then four agents reason over the result, the literature, and a library of reference flows.

Repository Paper

Simulation & optimization

DOpen source · GPL-3.0

DAFoam

He

Discrete adjoint with OpenFOAM for high-fidelity multidisciplinary design optimization. Used in more than 100 publications, with more than 50,000 Docker pulls. FROST's simulation agent builds on it.

Repository Docs
WMIn-house solver

Wall-modeled LES with droplet, roughness, and CHT models

Jain

The LES used for iced airfoils and wings, droplet impingement, and conjugate heat transfer. The solvers are not open source; FROST releases the validated setups and derived quantities.

Website
GHIn-house solver

GPU high-order DG LES

Gao

A GPU discontinuous-Galerkin LES that resolves the rime-iced S1223 with 346 M unknowns on one GPU.
