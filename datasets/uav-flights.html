What this dataset contains

Fixed-wing and quadcopter UAVs flown into natural icing. In one mission the aircraft drew over 80% more power in an icing loiter while its Pitot ports iced shut.

Flight logsOnboard video3D ice scannatural cloud

How it will appear in FROST

Every FROST record carries its conditions, instruments, uncertainty, and provenance. This is the planned record header for this dataset.

id frost://field/uav-flights origin measured formats MP4, Parquet, STL/PLY metadata Croissant + icing vocabulary: (V∞, T∞, LWC, MVD, t_ice, α, Ω, Re) integrity SHA-256 per file · W3C PROV lineage · curator-signed access Open tier expected (CC-BY-4.0), subject to export-control screening release FROST v1.0 · DataCite DOI minted at release
